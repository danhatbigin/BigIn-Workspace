## Scope

Đọc HeroUI v3 index, official agent skill, MCP/AGENTS docs và component docs; cài HeroUI Free + Tailwind v4; dùng component chính thức cho actions/inputs; polish typography, contrast, spacing, calendar, drawer, duplicate và motion settings. ## Hướng thiết kế

Dashboard làm việc: neutral surfaces, text dark rõ ràng, accent blue, project colors riêng, warning orange. Heading gọn hơn; chữ body/form 13–15px; icon targets 36px+; thông tin thời gian và hành động ưu tiên. Không dùng đoạn editorial/leaf card như trọng tâm. Giữ calendar custom vì đây là time logging/multi-select workflow, không phải date picker đơn giản.

HeroUI v3 sử dụng compound APIs, onPress/isDisabled, Tailwind v4/styles import đúng thứ tự; không thêm HeroUIProvider v2. Motion registry vẫn là source timing; không để HeroUI và Motion cùng animate một property. MCP docs đã đọc nhưng chưa thêm MCP config vào máy.
